# SOTERIA ROOM

SOTERIA ROOM은 YouTube 재생목록을 중심으로 음악을 고르고, 찾고, 겨루고, 다시 듣기 위한 개인 음악 보관실입니다. 채널의 공개 재생목록을 가져와 월별 픽, 큐레이션, 리캡 시리즈, 카와이 보이스 시리즈로 정리하고, Pick과 랜덤 디깅, 음악 월드컵, 채널 보관실을 한 화면에서 사용할 수 있게 만들었습니다.

- 공개 사이트: https://soteria-room.workspace-304435.chatgpt.site
- 외부 LLM 검토용 설명: [SITE_REVIEW_GUIDE.md](./SITE_REVIEW_GUIDE.md) · [원문 읽기](https://raw.githubusercontent.com/dudwls9383/soteria_room/main/SITE_REVIEW_GUIDE.md)

영상과 음원 파일은 저장하지 않습니다. 앱은 YouTube의 공개 정보와 로컬 저장소에 보관한 메타데이터를 사용합니다.

## 주요 기능

### 듣기 목록과 계절 테마

메뉴는 핵심(픽·월별 큐레이션·디깅·리캡·카와보), 도구(검색기·링크 추출기·월드컵), 탐색(하꼬 추천·채널 보관실·곡추천 병), 연결(블로그·갤러리), 관리로 나뉩니다. 재생기의 전체 모드는 화면을 큰 영상과 오른쪽 듣기 목록으로 나누며, 모바일에서는 세로로 이어집니다. 기본 모드로 돌아오거나 Esc로 나와도 재생은 유지됩니다.

- 하단에서 자동·봄·여름·가을·겨울 테마 선택. 선택은 브라우저에 기억합니다.
- 첫 접속에 약 1.8초의 로고·음파 입장 연출. 데이터 동기화를 기다리지는 않습니다.
- 디깅의 Pick/랜덤, 검색 결과, 재생목록 상세, 곡추천 병에서 임시 듣기 목록에 곡을 담습니다.
- 공통 YouTube 재생기는 탭을 옮겨도 유지됩니다. 이전/다음, 곡 종료 후 다음 곡, 순서 변경, 삭제, 셔플, 볼륨, 재생 위치 조절을 지원합니다. 월드컵으로 이동하면 공통 재생을 일시정지합니다.
- 듣기 목록은 서버에 저장하지 않고 새로고침하면 비워집니다.
- 앰비언트는 현재 곡의 썸네일을 흐린 배경으로 사용합니다. 영상 프레임의 실시간 색상 추출은 하지 않습니다. 끔·은은하게·몰입과 0~100% 강도 슬라이더를 지원합니다.
- 모바일은 영상과 조작 영역을 세로로 배치하며, 시스템의 모션 줄이기 설정을 존중합니다.

### 영상 정보와 부분 갱신

- 가져오기 · 동기화의 **최신 월의 픽만 갱신**, 재생목록 상세의 **이 목록만 갱신**으로 곡 추가·삭제·교체·순서를 반영합니다. 곡 수가 같아도 전체 내용을 다시 읽고 다른 목록은 유지합니다. 방문자도 실행할 수 있으며 동시 동기화 잠금과 1분 연속 요청 제한을 적용합니다. 실패·중단 응답은 기존 자료를 덮어쓰지 않습니다.
- **영상 정보 갱신**은 관리자 전용이며 조회수·게시일·길이·사이트 내 재생 가능 여부를 50곡씩 조회합니다. 7일 이내 정보는 재사용하고, 중단 시 완료한 묶음은 유지합니다.
- 디깅의 **숨은 곡 Pick**은 확인된 큐레이션 영상에서 조회수·영상 길이·게시연도 조건에 맞는 곡을 낮은 조회수 순으로 미리 보여줍니다. 미확인·오래된·재생 제한 정보는 결과에 포함하지 않습니다. 첫 사용에는 관리자 영상 정보 갱신이 필요합니다.
- **하꼬 추천 → 미리듣기**는 별도 카드에 최근 공개 영상 최대 6개를 표시하며 6시간 재사용합니다. 방송·잡담도 포함될 수 있습니다. 재생/목록 담기를 각각 지원합니다.
- 삭제·비공개·임베드 제한 영상은 관리자 목록에서 확인하며 원래 재생목록을 자동 삭제하지 않습니다. 공통 재생기는 실패 사유를 듣기 목록에 남기고, 선택한 경우 다음 재생 가능한 곡으로 이동합니다. 모든 곡이 실패하면 반복하지 않고 멈춥니다.
- 전체 모드 목록에는 곡 제목·아티스트·현재 곡 표시와 순서 변경·삭제 버튼을 표시합니다. 중복 곡 담기는 알림으로 안내합니다.
- **플레이어**는 작은 영상 재생기와 접을 수 있는 듣기 목록을 제공합니다. 곡을 재생하면 기본적으로 목록은 접혀 있으며, 목록 담기를 실행하면 펼쳐집니다. ×는 재생과 임시 목록을 모두 닫습니다. 하단에서 재생·이동·셔플·볼륨을 조절하고 앰비언트는 설정에서 끌 수 있습니다.

### Playlist Pick

홈에서 가장 먼저 보이는 재생목록 추천 영역입니다. 채널에서 가져온 재생목록 중 월의 픽과 큐레이션을 중심으로 보여주며, `202X.XX`처럼 수집 목적이 강한 목록은 별도 보관함으로 분리합니다.

- 월의 픽 우선 노출
- 재생목록 제목, 곡 수, 조회수, 갱신일 기준 정렬
- 오름차순/내림차순 전환
- 커스텀 재생목록 표지 우선 사용
- My Recap 2026~2021 시리즈 분리
- Kawaii Voice Playlist 시리즈 분리

### YouTube Playlist Searcher

가져온 모든 재생목록 안에서 곡을 검색합니다.

- 곡 제목, 채널명, 재생목록명 검색
- 전체, 픽, 큐레이션, 수집, 리캡, 카와이 보이스 시리즈 범위 필터
- YouTube 링크 일괄 복사
- 같은 영상 ID는 하나로 합쳐서 표시

### Playlist Link Extractor

커뮤니티에 재생목록을 공유하기 쉽게 영상 링크를 한 번에 뽑습니다.

- 저장된 재생목록 선택
- 링크만, 제목+링크, 마크다운 형식 전환
- 공유용 텍스트 한 번에 복사

### Digging

수집한 음악과 구독 채널을 더 가볍게 탐색하는 공간입니다.

- Pick: 접속하면 바로 보이는 오늘의 추천 선반
- 이번 달, 분기, 연도, 오래전에 모은 음악 기준 Pick
- 각 선반별 `다른 곡 보기`
- 랜덤 곡 뽑기
- 랜덤 채널 뽑기
- YouTube Subscription Manager JSON으로 채널 보관실 갱신
- 태그별 채널 필터와 앨범형 바둑판 목록

현재 Pick은 수집 시점과 재생목록 문맥을 기준으로 고릅니다. 영상별 조회수, 발매일, 장르 점수까지 반영하는 추천 DB는 다음 단계에서 붙일 수 있도록 분리해 두었습니다.

### Song Bottle Light

Song-Bottle 프로젝트를 참고한 가벼운 곡추천 탭입니다. 로그인 없이 곡 제목, YouTube 링크, 짧은 메모를 남기고 최신 추천을 함께 볼 수 있습니다.

### Music World Cup

가져온 재생목록으로 음악 이상형 월드컵을 진행합니다.

- 재생목록 선택 후 4강~64강 시작
- YouTube 임베드 재생
- 우승곡 기록
- 전체 랭킹 합산
- 체험용 데모 월드컵

월드컵 결과는 이 브라우저에서 시작한 게임을 기준으로 저장합니다.

### Blog & Galleries

네이버 블로그, 소무니아 갤러리, 카와이 보이스 갤러리의 최신 글을 가볍게 연결합니다.

- 최신 글 목록 표시
- 원문 바로가기
- 서버 메모리 5분 캐시

전체 과거 글을 저장하는 크롤러는 아닙니다. 원문 사이트가 차단하거나 화면 구조를 바꾸면 직접 방문 링크와 오류를 표시합니다.

### Translation

상단 언어 버튼으로 한국어, 영어, 일본어 UI를 전환합니다. Google Translate 리다이렉트를 사용하지 않고 앱 내부 문구를 바꾸는 방식이라 지역 제한 페이지로 이동하지 않습니다.

## 로컬에서 실행하기

Windows에서는 `SOTERIA-ROOM.cmd`를 더블 클릭하면 됩니다. 실행 창을 열어둔 상태에서 브라우저로 아래 주소에 접속하세요.

```text
http://localhost:5173/
```

처음 실행할 때는 필요한 패키지를 설치하므로 시간이 조금 걸릴 수 있습니다. Node.js 22.13 이상이 필요합니다.

직접 실행하려면:

```powershell
node scripts/local-start.mjs
```

종료할 때는 실행 창에서 `Ctrl+C`를 누릅니다.

## 재생목록 갱신 방식

앱은 고정된 @soteria_room 채널의 공개 재생목록을 갱신합니다. 마지막 전체 실행 시작으로부터 24시간이 지난 뒤 관리자 접속에서 자동 갱신하며, 화면을 계속 열어두면 매시간 갱신 시기를 확인합니다. 접속자가 없을 때 별도 예약 작업을 실행하는 방식은 아닙니다. 서버의 작업 목록과 잠금으로 중복 실행을 막고, 닫힌 탭의 미완료 작업은 다음 관리자 접속에서 이어갑니다.

- 1차·2차 전체 동기화, 실패 목록 재시도·중단은 관리자 인증이 필요합니다. 24시간 이내 자동 갱신은 기존 결과를 사용하며, 관리자의 수동 재시도는 즉시 가능합니다.
- 마지막 전체 성공 시각은 모든 목록이 성공한 경우에만 서버에 기록합니다. 개별 추가 시각과 구분합니다.
- 직접 추가·삭제, JSON·CSV 업로드는 관리자 키 확인이 필요합니다. `SOTERIA_ADMIN_KEY`를 서버 환경 변수로 설정하며, 키를 소스에 넣지 않습니다.
- 초기 전송에서 중복 곡을 한 번만 보내고, 재방문 시 브라우저의 읽기 전용 캐시를 먼저 보여줍니다.
- 실패한 목록은 기존 저장 내용을 유지합니다.
- 채널에서 사라진 목록은 자동 삭제하지 않습니다.
- 0곡 또는 1곡 목록도 보관할 수 있습니다.
- 월드컵에는 최소 2곡이 필요합니다.
- `YOUTUBE_API_KEY`는 선택 사항입니다.

월별 분류는 `2026.09`, `9월의 픽(2026)` 같은 제목에서 읽습니다. 여러 달 범위이거나 날짜가 없는 목록은 큐레이션 또는 그 밖의 재생목록으로 남깁니다.

## 데이터 저장

로컬 실행 시 데이터는 `.wrangler/state/` 아래의 D1 호환 SQLite 저장소에 보관됩니다. 이 폴더는 Git에 올리지 않습니다.

보관되는 데이터:

- 가져온 재생목록과 곡 목록
- 재생목록 표지, 조회수, 갱신일 메타데이터
- 월드컵 게임과 결과
- 구독 채널 JSON에서 만든 채널 보관실 데이터
- 곡추천 병에 남긴 최신 추천

브라우저별 설정과 일부 상태는 브라우저 로컬 저장소에 남습니다.

## 운영 메모

### 동기화와 자료 초기화 (2026-09-29)

- 동기화 중단은 두 단계의 실행 권한을 회수하고 대기열을 보존합니다. 중단 후 자동 재개하지 않으며 버튼으로 다시 시작할 수 있습니다. 이미 전송한 외부 요청은 끝날 수 있지만 결과를 저장하지 않습니다.
- YouTube HTTP 429를 받으면 남은 목록을 계속 요청하지 않고 중단합니다. 수동 재시도는 가능하지만 제한 해제 시각을 보장하지 않습니다.
- 랜덤 채널의 전체보기는 100개 단위 페이지와 이름 검색을 제공합니다. CSV를 구독목록 기준으로 삼고 저장된 JSON에서 같은 채널 ID의 사진을 보충하며, 전체보기 때문에 YouTube 채널을 추가 조회하지 않습니다.

- 1차: 월의 픽, My Recap, Kawaii Voice Playlist, 기타 큐레이션. 관리자 접속 시 하루 한 번 자동으로 갱신합니다.
- 2차: 202X.XX 월별·연간 수집, A bundle of songs. 사용자가 2차 동기화를 눌렀을 때만 수집하며 다음 방문 시 자동 재개하지 않습니다.
- 단계별 대기열·실패·완료 시간을 분리하고 최근 12개 로그를 작게 표시합니다. 실패 재시도에는 대기시간이나 횟수 제한이 없으며 동시 중복 실행만 방지합니다.
- 동기화 화면에서 재생목록 DB·JSON·CSV 초기화를 각각 선택할 수 있습니다. 각 원래 탭의 초기화 버튼도 유지합니다.

- 첫 화면은 표지·곡 수·첫 곡만 먼저 읽고, 전체 곡 정보는 검색 탭이나 개별 목록을 열 때 읽습니다.
- 전체 동기화는 관리자만 실행할 수 있습니다. 최신 월의 픽 한 개 갱신과 기록 조회는 공개되어 있습니다. 하루 한 번 갱신하며 여러 방문자의 중복 수집을 서버에서 막습니다. 방문 시 갱신은 화면을 가리지 않고 진행됩니다.
- 곡 수와 첫 곡이 같고 최근 7일 안에 수집한 목록은 건너뜁니다. 완전한 변경 감지는 아니므로 같은 곡 수의 중간 곡 교체도 반영하도록 7일 이후에는 다시 읽습니다.

## 하꼬 추천

`채널 탐색` 안의 `하꼬 추천 / 채널 보관실`에서 채널을 탐색합니다. 하꼬 추천은 CSV 구독목록에 JSON의 태그·사진·구독자 수를 보충하며 CSV 저장본이 없으면 JSON 채널목록을 사용합니다. 전체와 1만 명 이상부터 0–99명까지 구간을 높은 순으로 표시하며, 목록도 구독자 수가 많은 순입니다. 태그·이름 검색, 랜덤 12개, 60개 단위 전체보기를 제공합니다. 미확인은 0명으로 취급하지 않습니다. 태그의 원본 ID는 유지하고 메이저 남 → 우타이테 남 → 메이저 여 → 우타이테 여 → 작곡가 → 토픽 → 플레이리스트 → ASMR → 일본 → 한국 순으로 표시합니다.

숨은 곡 Pick은 50·100·200·500·800회 이하 구간과 12곡씩 페이지 넘기기를 지원합니다. 랜덤 뽑기는 결과만 보여주며 재생과 듣기 목록 담기를 직접 선택합니다. YouTube Music에서 생성된 LR 리캡은 공식 API에서 조회되지 않아 공개 재생목록 페이지로 가져옵니다.

공식 구독자 갱신을 사용하려면 YouTube Data API v3를 활성화한 서버용 키를 Sites 비밀 환경변수 `YOUTUBE_API_KEY`로 설정합니다. 키는 코드나 브라우저에 저장하지 않습니다. 이 사이트는 해당 키가 있으면 재생목록 수집에도 공식 API를 사용합니다. 키가 없을 때도 JSON 기반 추천은 동작합니다.

관리자만 공식 갱신을 실행할 수 있으며, 7일 이상 지난 채널을 요청당 최대 50개씩 처리합니다. 완료된 묶음은 저장되며 중단 후 다음 실행에서 이어집니다. 누락·비공개 수치는 미확인으로 저장합니다. 공개 구독자 수는 근삿값일 수 있으며 카드에 자료 출처와 저장·확인 날짜를 표시합니다. 방문 시 공식 갱신은 실행하지 않습니다.


### 탐색 화면 다듬기

랜덤 채널의 전체 구독목록은 항상 펼쳐지며, 뽑은 결과가 조작 영역과 전체 목록 사이에 표시됩니다. 숨은 곡 Pick은 가로 한 줄과 제목 옆 다른 곡 보기 버튼을 지원하고 필터·페이지 이동을 유지합니다. 채널 탐색의 하위 탭은 디깅과 같은 가로 모양이며 추천 채널은 사진을 키운 앨범형 카드로 표시합니다. 목록 이동·삭제 버튼은 한 줄에 묶었습니다. 월드컵 탭을 열어도 음악은 계속 재생하며, 월드컵 곡을 직접 재생할 때만 기존 플레이어를 중지합니다. 재생기 내부의 원본 영상에 포함된 검은 여백은 자르지 않습니다.

플레이어의 PiP 모드는 사이트 안에서 약 376px 너비로 떠 있는 작은 영상 모드입니다. 브라우저 바깥 별도 창은 아닙니다. 같은 iframe을 유지하므로 기본·전체·PiP 전환과 목록 접기에도 재생이 이어집니다. PiP에서는 별도 조작 바를 접고 YouTube 기본 컨트롤을 사용하며 설정과 목록은 작은 상단 버튼으로 엽니다. 재생 설정에는 닫기 ×가 있습니다.

모드 전환은 모든 모드에서 같은 버튼을 사용합니다. 현재 모드 아이콘을 누르면 그 자리에 전체·기본·미니 세 아이콘이 펼쳐지고 선택한 모드는 강조됩니다. 선택하거나 바깥을 클릭하면 다시 현재 아이콘 하나로 접힙니다.

앰비언트는 영상 색상을 밝은 배경과 섞어 유지하며, 글씨 색은 별도로 고정합니다. 앰비언트가 켜지면 카드·사이드바의 흰 배경을 더 받쳐 주고 보조 글씨의 투명도를 제거해 낮은 채도의 영상에서도 읽기 쉽게 표시합니다.
