# SOTERIA ROOM

YouTube 재생목록에서 음악을 고르고, 찾고, 함께 추천하는 음악 보관실입니다. 운영자의 월의 픽·수집 목록·리캡·카와보 시리즈를 탐색하고 사이트 안에서 재생하거나 임시 듣기 목록에 담습니다.

[공개 사이트](https://soteria-room.workspace-304435.chatgpt.site) · [외부 LLM 검토 설명](SITE_REVIEW_GUIDE.md) · [디자인 LLM 상세 인수인계](DESIGN_LLM_HANDOFF.md)

기준: **2026-10-05**. 현재 구현을 설명하며 실시간 곡 수·채널 수·구독자 수를 고정한 자료가 아닙니다.

### Pick과 랜덤

- 기간별 디깅 **Pick은 월의 픽만** 사용합니다. 숨은 곡은 기본 선택을 해제하면 저장된 전체 곡으로 확장할 수 있습니다. 202X.XX·A bundle of songs·기타 큐레이션·시리즈를 섞지 않습니다.
- 순서: 이번 달 → 분기별 → 그해의 음악 → 숨은 곡 → 오래전에 모아둔 음악.
- 별도 월의 픽 채널 추천 영역은 제거했습니다. 채널 탐색의 하꼬 추천·채널 보관실에 공통 ‘월의 픽 한정’ 필터가 있으며, 태그·구독자 조건·검색·랜덤·페이지에 함께 적용됩니다. 기본은 전체 자료입니다. 채널 ID를 우선하고 유일한 이름 완전 일치만 보조 연결합니다. 미확인 수치는 0으로 분류하지 않습니다.
- 연도·분기 선택줄은 분기별 Pick 바로 위에 있습니다. **연도는 분기와 그해 목록에, 분기는 분기 목록에만 적용**됩니다.
- 이번 달 자료가 없으면 최근 수집 월로 대체해 표시합니다. 오래된 음악은 현재 한국 시간의 같은 달을 과거 연도에서 찾아 ‘몇 년 전 이맘때’로 다시 보여줍니다. 연도별 기억을 선택할 수 있으며 정확한 수집일·발매일을 추정하지 않습니다.
- 일반 Pick은 한국 시간의 날짜·구역·곡 ID로 선택 순위를 정해 하루 동안 안정적으로 표시합니다. 다른 곡 보기로 해당 구역을 다시 뽑습니다.
- 숨은 곡은 확인된 조회수·길이·영상 업로드 연도로 필터링하고 12곡씩 넘깁니다. 조회수는 100,000회부터 50회까지 큰 순서입니다. ‘2025년까지’는 2025년 포함 이전 업로드입니다.
- 숨은 곡의 랜덤곡 보기는 조건 안에서 섞습니다. 가로 슬라이더 대신 카드 격자입니다.
- 별도 랜덤 뽑기에서는 전체·수집 목록 범위도 선택합니다. 뽑자마자 자동 재생하거나 담지 않습니다. 생성형 AI 추천은 없습니다.

### 재생과 연출

- 공통 YouTube 재생기·임시 목록: 담기, 중복 제거, 순서 이동, 삭제, 셔플, 이전·다음, 연속 재생.
- 기본 / 전체 / 미니 모드. 모드 아이콘을 누르면 세 선택지가 펼쳐집니다. 미니는 사이트 내부 영상이며 네이티브 PiP가 아닙니다.
- 목록 접기·설정 닫기·10초 이동. 기본 모드의 ×는 재생과 임시 목록을 모두 닫습니다.
- 탭 이동에도 재생 유지. 월드컵 진입은 유지하고 실제 후보를 재생할 때 공통 재생기를 일시 정지합니다.
- 썸네일 기반 앰비언트 강도 조절·끔, 자동·사계절 테마, 짧은 입장 모션, 밝은 Liquid Glass 패널.
- 실시간 영상 색 분석·음원 전용 재생은 아닙니다. 작은 영상은 유지하며 배경 효과를 꺼도 데이터 절약을 보장하지 않습니다.
- 공통 알림은 5초 후 닫히고 새 알림은 시간을 다시 시작합니다. 추천 병의 유리병·파도 SVG는 모션 줄이기를 따릅니다.

### 채널 자료

CSV는 구독 채널 기준 목록, JSON은 확장 프로그램의 채널·태그 보완 자료입니다. 서로 대체되는 파일이 아닙니다. 저장된 CSV가 있으면 기준 목록으로 사용하고 JSON·공식 API로 태그·사진·구독자 수를 보완합니다.

- 하꼬 추천: 구독자 구간, 태그·이름 검색, 랜덤·전체 목록, 60개 페이지, 미리듣기. 미확인 구독자 수는 0명이 아닙니다.
- 구간은 전체·1만 이상부터 작은 순서로, 1만 미만 전체·미확인도 제공합니다.
- 태그: 메이저 남 → 우타이테 남 → 메이저 여 → 우타이테 여 → 작곡가 → 토픽 → 플레이리스트 → ASMR → 일본 → 한국. 원본 ID는 유지합니다.
- 채널 보관실은 JSON 태그별 앨범형 목록입니다. ASMR은 독립 대메뉴가 아닌 태그입니다.
- 랜덤 채널 결과는 뽑기 영역과 항상 펼친 전체 구독 목록 사이에 표시합니다.
- 관리자 구독자 갱신은 최대 50개씩, 관측값은 7일간 재사용합니다. 방문자마다 전체 API를 호출하지 않습니다.

## 권한과 동기화

| 작업 | 권한·동작 |
| --- | --- |
| 저장 자료 탐색·재생·검색·로그 | 누구나 |
| 링크 추출·월드컵의 개인 목록 입력 | 누구나; 운영자 보관실에 저장하지 않는 일회성 입력 |
| 최신 월의 픽 / 선택 목록만 갱신 | 누구나; 기존 목록 다시 읽기, 연속 요청 1분 제한 |
| 1차 큐레이션 / 2차 대용량 동기화 | 관리자; 1차는 월의 픽·시리즈·기타 큐레이션, 2차는 수동 수집 |
| 실패 재시도·중단·직접 저장·삭제 | 관리자 |
| JSON/CSV 교체·초기화, 구독자·조회수 갱신 | 관리자 |
| 곡추천 작성 | 누구나; 방문자 기준 시간당 8개, 최신 40개 표시 |
| 곡추천 삭제 | 관리자; 카드에서 확인 후 해당 추천만 영구 삭제 |

서버의 `SOTERIA_ADMIN_KEY`와 요청 헤더로 인증합니다. 입력한 키는 해당 브라우저 탭 세션에 유지하며 값 자체를 소스·문서에 넣지 않습니다.

1차 자동 갱신은 **관리자가 잠금을 연 상태로 접속**하면 24시간 기준으로 확인합니다. 무인 예약 작업이 아니며 일반 방문자의 접속으로 전체 수집을 시작하지 않습니다. 저장된 대기열·소유권 잠금으로 중복 수집을 막고 HTTP 429에서는 남은 목록을 보존한 채 멈춥니다.

최근 목록의 곡 수·첫 곡이 같으면 건너뛰고 7일 이후 다시 읽습니다. 같은 개수의 중간 편집을 놓칠 수 있으므로 편집 중인 픽은 단일 갱신을 사용하세요.

**새 목록 발견과 기존 목록 갱신은 다릅니다.** 새 월의 픽은 관리자 1차 동기화로 발견해야 최신 표시·대상이 바뀝니다. 공개 단일 갱신은 새 목록을 찾지 않습니다. 갱신 로그는 목록별 최근 12개를 저장합니다.

재생목록 DB·JSON·CSV 초기화는 독립 버튼입니다. 재생목록 초기화는 추천·월드컵 기록을 지우지 않습니다. 추천 삭제는 이미 담긴 듣기 목록이나 YouTube 원본을 지우지 않습니다.

## 로컬 실행

Node.js **22.13 이상**이 필요합니다. Windows에서는 [SOTERIA-ROOM.cmd](SOTERIA-ROOM.cmd)를 실행하거나:

```sh
npm ci
npm run local
```

기존 자료를 지우지 않고 로컬 DB를 준비해 http://localhost:5173 에서 실행합니다. 실행 창을 닫으면 로컬 접속은 종료됩니다. 공개 사이트의 서버·DB는 별개입니다.

[.env.example](.env.example)을 참고해 `.env.local`에 선택 설정을 넣습니다.

```env
YOUTUBE_API_KEY=
SOTERIA_ADMIN_KEY=
```

공개 재생목록은 키 없는 읽기 경로도 있지만 구독자 수·조회수·채널 미리듣기 등 공식 API에는 YouTube 키가 필요합니다. 공개 HTML은 구조 변경·429에 영향을 받습니다. 키를 커밋하지 마세요.

```sh
npm run dev           # DB 준비 후 개발
npx tsc --noEmit
npm test
node --experimental-strip-types --test tests/picks.test.ts
node --experimental-strip-types --test tests/pick-tools.test.ts
npm run build
npm start             # 빌드된 Worker의 로컬 실행
```

Pick 전용 테스트는 `npm test`에 포함되지 않아 별도로 실행합니다. 통합 테스트는 외부 호출·로컬 자료 변경이 있으므로 내용을 확인하세요.

## 범위와 한계

첫 HTML에는 로딩 UI만 보일 수 있습니다. 브라우저가 API로 채우므로 크롤러가 자료를 못 읽었다고 장애를 단정하지 마세요. 외부 LLM에는 문서와 실제 스크린샷을 함께 전달하세요.

음원·영상 파일을 자체 공급하지 않습니다. YouTube 삭제·비공개·임베드·지역/브라우저 제한으로 재생이 안 될 수 있습니다. API 상태와 실제 플레이어 오류는 구분합니다.

숨은 곡은 확인된 영상 정보가 필요하며 미확인 조회수를 0회로 추정하지 않습니다. 큰 영상 관리 패널은 제거했고 작은 관리자용 조회수 갱신만 남겼습니다. `components/video-management.tsx`는 미사용 파일입니다.

AI 추천, 자체 음악 서버, 사용자별 영구 보관실, 회원·댓글·좋아요, 갤러리 목차별 채널 자동 추출은 현재 기능이 아닙니다.

## 연결된 공간

블로그와 소무니아·카와이 보이스 갤러리를 `#connected` 한 화면에 모았습니다. 전체·출처 필터, 제목·설명 검색과 더 보기로 탐색합니다. 블로그에는 RSS에 포함된 대표 이미지를 표시하며, 이미지가 없거나 표시되지 않으면 카드의 제목과 설명을 유지합니다. 갤러리는 말머리·댓글 수·조회수와 원문 링크를 담은 작은 목록입니다.

각 원문에서 최근에 제공하는 글을 대상으로 합니다. 모든 과거 글을 수집하지 않습니다. 기존 `#blog`, `#somunia`, `#moesound` 공유 주소는 통합 화면의 해당 출처로 이어집니다. 글 목록은 출처별로 서버에 저장하고 약 10분 간격으로 갱신합니다. 새 글을 확인하지 못하면 이전 목록과 출처별 상태를 표시합니다. 갤러리 글 본문은 요청한 글만 확인해 미리보기를 제공하고, 공개된 YouTube 영상 링크가 확인되면 사이트 플레이어에서 듣거나 임시 목록에 담을 수 있습니다. 원문 글·작성자 이름·설명은 번역하지 않고 UI만 한국어·일본어·영어로 표시합니다.
